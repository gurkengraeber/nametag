Nametag has a few single-key shortcuts for the things you do most. They work on every page once you are signed in. Press `?` at any time to see the list in the app, or choose "Keyboard shortcuts" in the user menu on a desktop screen.

## Shortcuts

| Key | What it does |
| --- | --- |
| `/` | Jump to the search field |
| `Ctrl+K` or `Cmd+K` | Jump to the search field |
| `N` | Add a new person |
| `?` | Show or hide the shortcut help |
| `G` then `D` | Go to the dashboard |
| `G` then `P` | Go to people |
| `G` then `G` | Go to groups |
| `G` then `M` | Go to the map |
| `G` then `J` | Go to the journal |
| `G` then `R` | Go to relationship types |

For the `G` shortcuts, press `G`, release it, and press the second key within about a second and a half.

## When shortcuts are off

Shortcuts never fire while you are typing in a text field, a note or a dropdown, so writing a name with an "n" in it is safe. They are also off while a dialog or the phone menu is open, and any combination with `Ctrl`, `Cmd` or `Alt` is left to your browser. Letters are matched by key position, so they work on keyboard layouts that do not type Latin letters. The `/` key works where it needs `Shift`, as on a German keyboard.

## In the search

Inside the search results: `Up` and `Down` move through the hits, `Enter` opens the profile, `Shift+Enter` or `Tab` shows the quick actions and `Esc` closes them. See [Search](/features/search/) for details.

## On a phone

Phones have no keyboard to speak of, so the phone header offers a New person button and shows the section you are in. The menu marks the current page and closes with `Esc` when a keyboard is attached.
